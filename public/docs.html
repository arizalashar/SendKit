Pengenalan SendKit API

SendKit adalah middleware API yang mempermudah pengiriman WhatsApp (via Fonnte) dan Email (via Brevo). Setiap endpoint API (kecuali autentikasi) wajib menggunakan header `x-api-key`.

HEADER WAJIB x-api-key: <API_KEY_ANDA>
POST

/auth/register

Registrasi pengguna baru untuk mendapatkan kuota pesan sandbox gratis.

PAYLOAD REQUEST 
{
  "name": "Dev User",
  "email": "dev@email.com",
  "password": "secretpassword"
}
RESPONS SUKSES 
{
  "success": true,
  "message": "Registrasi berhasil.",
  "data": {
    "id": 1,
    "name": "Dev User",
    "api_key": "UUID-KEY",
    "quota": 1000
  }
}
POST

/auth/login

Verifikasi kredensial akun dan dapatkan token JWT untuk otorisasi dashboard.

PAYLOAD REQUEST 
{
  "email": "dev@email.com",
  "password": "secretpassword"
}
RESPONS SUKSES 
{
  "success": true,
  "data": {
    "token": "JWT_TOKEN",
    "user": { "id": 1, "name": "Dev User" }
  }
}
POST

/api/send/wa

Kirim notifikasi pesan WhatsApp via Fonnte gateway.

PAYLOAD REQUEST 
{
  "to": "628123456789",
  "message": "Halo dari SendKit API!"
}
RESPONS SUKSES 
{
  "success": true,
  "message": "Pesan WhatsApp berhasil dikirim.",
  "data": { "recipient": "628123456789", "status": "sent" }
}
CURL CONTOH
POST

/api/send/email

Kirim email dengan dukungan format HTML penuh lewat SMTP Brevo.

PAYLOAD REQUEST 
{
  "to": "user@email.com",
  "subject": "Judul",
  "message": "
Isi HTML
"
}
RESPONS SUKSES 
{
  "success": true,
  "message": "Email berhasil dikirim.",
  "data": { "recipient": "user@email.com", "status": "sent" }
}
POST

/api/send/otp/wa

Menghasilkan 6 digit OTP acak dan mengirimkannya langsung ke WhatsApp tujuan.

PAYLOAD REQUEST 
{
  "to": "628123456789"
}
RESPONS SUKSES 
{
  "success": true,
  "message": "OTP berhasil dikirim via WhatsApp."
}
POST

/api/send/otp/email

Menghasilkan 6 digit OTP acak dan mengirimkannya lewat template HTML email yang rapi.

PAYLOAD REQUEST 
{
  "to": "user@email.com"
}
RESPONS SUKSES 
{
  "success": true,
  "message": "OTP berhasil dikirim via Email."
}
POST

/api/verify/otp

Verifikasi kode OTP. Memeriksa kecocokan nomor, kesesuaian kode, kedaluwarsa 5 menit, dan status verifikasi.

PAYLOAD REQUEST 
{
  "to": "628123456789",
  "otp": "123456"
}
RESPONS SUKSES 
{
  "success": true,
  "message": "Verifikasi OTP berhasil. Kode valid.",
  "data": { "verified": true }
}
